# FocusZone 🎯

FocusZone is a full-stack productivity web application designed to help students stay focused during study sessions.

The application allows users to manage tasks, start focused study sessions, manage blocked applications, and configure study locations.

## 📌 What it Does

FocusZone helps students reduce distractions and maintain productive study sessions by combining task management, focus sessions, blocked apps, and study-location features in one application.

## ✨ Features

- 🔐 User Login and Account Management
- 📝 Task Management
- ⏱️ Focus Study Sessions
- 🚫 Blocked Apps Management
- 📍 Study Location Management
- 📊 Focus Statistics
- ⚙️ User Settings
- 🗄️ Database Integration
- 🔗 REST API Backend
